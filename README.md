# The-Language-of-Chips
This repository contains the preliminary results for the QIF proposal entitled "The Language of Chips: A Unified AI-Driven Framework for Provably Secure RTL2GDS Flow"
Here, we present a few promising results that make our proposed AI-based EDA tool optimistic and competent. Our AI tool is purely RAG-based and currently not finetuned on this data corpus.

The repository comprises two folders: 1. \generic_gate-level_netlists, 2. \ti_masked_HDLs
\generic_gate-level_netlists contains the preliminary results of the generic gate-level netlists of a few behavioral HDLs, which are generated by our indigenous AI tool. 
\ti_masked_HDLs contains the preliminary threshold implementation masked HDLs generated by our AI tool.
